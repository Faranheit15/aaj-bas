# Architecture Decision Records

ADRs document material architecture, dependency, security, privacy, and product-scope decisions. Start with [the template](TEMPLATE.md) and retain superseded decisions for the audit trail.

- [ADR-0001: Initial architecture](0001-initial-architecture.md) — extended by ADR-0002 and ADR-0003; the Cloudflare Pages hosting it records as a future target is now live, and its shared-package list has since gained `packages/logger`.
- [ADR-0002: Cloudflare Pages continuous deployment](0002-cloudflare-pages-continuous-deployment.md) — extended by ADR-0004; reaching `develop` now requires a reviewed pull request, though the deployment it triggers is unchanged. The `VITE_APP_URL` it describes is now the reader's stable production alias rather than the per-commit deployment URL, which is what makes its own rollback plan work; the deployment topology it records is otherwise unchanged.
- [ADR-0003: Shared logging package](0003-logging-package.md)
- [ADR-0004: Reviewed pull requests on develop](0004-reviewed-pull-requests-on-develop.md)
- [ADR-0005: Edition content contract](0005-edition-content-contract.md) — the first public data contract; closes four gaps PRD section 13 left, and fixes the topic vocabulary written into every published edition.
- [ADR-0006: Published content in the reader build](0006-published-content-in-the-reader-build.md) — extends ADR-0002 and ADR-0005; the reader deployment now carries content, `/content/latest.json` becomes a second published artifact, and the AB-103 publish gate is what keeps development sample data out of production.
- [ADR-0007: Versioned on-device state](0007-versioned-on-device-state.md) — extended by ADR-0008; the first data the product persists to a reader's device, and it sets the version, migration, eviction, and never-clobber-a-newer-document rules that AB-203, AB-204, AB-205, and AB-206 all inherit. Its statement that "every value stored is already public" no longer holds now that the document carries interests the reader chose, and the discard-on-unmigratable rule it accepted is narrowed by ADR-0008.
- [ADR-0008: Reader-chosen interests](0008-reader-chosen-interests.md) — extended by ADR-0009, which applies its leniency criterion to the theme vocabulary and takes up the settings-surface question it deferred; its statement that a ready page carries no links at all is now "exactly one, a same-document skip link to `main`", and the argument against a `/settings` route is unaffected because no route is reachable from it. Extends ADR-0007; the first stored value a reader states rather than one the product observes. Fixes that interests substitute two of the ten stories rather than adding any, sets the criterion for validating a product-owned vocabulary leniently, and re-argues discarding a document for a payload that cannot be re-derived by looking.
- [ADR-0009: Theme, and accessibility verification without a browser](0009-theme-and-accessibility-verification.md) — extends ADR-0007 and ADR-0008; themes the reader by an attribute whose absence means "the operating system decides", pins it before the first paint, and records why axe-core was NOT added — under jsdom it cannot check contrast or touch targets, which are the two things AB-205 is for, so contrast became arithmetic over the palette and a browser-based check is deferred with its reason written down.
- [ADR-0010: Offline support, and the browser that verifies it](0010-offline-support-and-browser-verification.md) — extends ADR-0002 and ADR-0006; the first artifact this product installs on a reader's device that a redeploy does not reliably replace. Hand-writes the worker rather than adding 300+ packages, keeps editions network-first so a correction can never be hidden from an online reader, and adds Playwright for four specs because "opens in airplane mode" is not a property of any source text. ADR-0002's rollback surface is now conditional on two invariants this record names.
- [ADR-0011: The measurement vocabulary, and why nothing collects yet](0011-measurement-vocabulary.md) — extends ADR-0003 and answers the delegation ADR-0008 left open. Closes the event vocabulary, refuses the installation identifier, and ships no adapter: three of PRD section 15's four event families are already answerable without client code, and the fourth waits for an endpoint. Makes `SECURITY.md`'s "no reader data leaves the reader's device" a checked property of the whole reader, and falsifies ADR-0003's statement that no repository check would catch a patched console.
